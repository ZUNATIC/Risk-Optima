# AEGIS-CORE // Tactical Security Intelligence & Criticality Engine

AEGIS-CORE is an enterprise-grade asset criticality and risk topology framework designed for Security Operations Centers (SOC) and Incident Response teams. It implements weighted multi-variable risk scoring models based on NIST SP 800-30 guidelines.

## Key Features
- **Tactical Criticality Engine:** Computes weighted risk scores using Impact, Likelihood, RTO, and Exposure vectors.
- **Automated Tier Classification:** Instantly categorizes assets from Tier 1 (Critical) to Tier 5 (Informational).
- **Cross-Category Breach Simulation:** Maps cascading downstream attack paths across enterprise architecture.
- **Executive PDF Reporting:** Generates downloadable professional PDF risk reports for leadership.
- **Bulk & Manual Ingestion:** Supports CSV/TXT bulk uploads with a downloadable sample template.
- **Live Search & Filtering:** Real-time asset filtering across the live operational matrix table.

## Technology Stack
- **Backend:** Python, Flask, SQLite, ReportLab
- **Frontend:** HTML5, Bootstrap 5, Chart.js, JetBrains Mono, Custom Cyber SOC CSS
